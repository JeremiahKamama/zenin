# Zenin Documentation

Zenin is a multi-asset investment intelligence workspace for individual investors. This page points you to the right documentation.

> Zenin provides research and decision-support tools only. It is **not** investment, tax, legal, or financial advice.

## I am a user

Start with the public portal:

- **[Get started](/get-started/what-is-zenin)** — what Zenin is, create a workspace, connect data sources, your first portfolio sync, and troubleshooting.
- **[Use Zenin](/use-zenin/portfolio-and-connected-accounts)** — portfolio and connected accounts, trades and journal, notifications, watchlists and research, analytics, and the data status glossary.

## I build or operate Zenin

Internal engineering and operations documentation lives in the repository, not in this public portal:

- **Repository `docs/internal/`** — architecture, portfolio and provider operations, notifications operations, local development, and deployment/incident response.
- These documents are internal-only and are not deployed to the public site.

## I want engineering evidence / audits

Deep audits and migration plans are retained as historical evidence:

- **Repository `docs/internal/architecture/audits/`** — each audit is marked with `status`, `last_verified`, and whether it is `current`, `historical`, or `proposed`.
- Audits are evidence of engineering decisions. They are not user guides. Public user documentation is task-oriented and lives in this portal.
